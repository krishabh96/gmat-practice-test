🚀 Deploy to Vercel — Step by Step
1
Click "Download questions.js" above
The file downloads to your computer with all questions baked in.
2
Go to your GitHub repo
Open github.com/yourusername/gmat-practice-test in your browser.
3
Replace questions.js
Click questions.js in your repo → Edit (pencil icon) → delete all content → paste new content. Or drag-and-drop the file via Add File → Upload files.
4
Commit the change
Scroll down → click Commit changes. Vercel detects the change automatically.
5
Done — live in ~30 seconds
Visit gmat-practice-test.vercel.app — your users will see the updated questions immediately.
