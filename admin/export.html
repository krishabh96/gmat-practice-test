How Supabase Flow Works
Old flow (localStorage): Add questions → Export questions.js → Push to GitHub → Wait for Vercel deploy

New flow (Supabase): Add questions → Done! ✅

Questions save to Supabase instantly. Test pages fetch from Supabase when a user starts a test. No export, no GitHub push, no redeploy needed for question updates.

You only need to push to GitHub when you change code files (HTML, JS, CSS).
